모든 기록은 이 브라우저(localStorage)에 저장돼요. 아래 동기화를 켜면 컴퓨터와 아이폰이 같은 기록을 함께 써요.

☁️ 컴퓨터 ↔ 아이폰 동기화 꺼짐

GitHub 비공개 Gist에 내 기록만 따로 저장하고, 같은 토큰을 넣은 기기끼리 주고받아요. 공개 저장소(GitHub Pages)에는 기록이 올라가지 않아요.

자동 동기화기록이 바뀌면 1.5초 뒤에 조용히 저장해요
열려 있을 때 새로고침화면을 볼 때 15초마다 · 창을 다시 열면 바로
마지막 동기화아직 없음
Gist-
🔐 보안 수칙
· 토큰은 gist 하나만 체크한 Personal Access Token(classic)을 쓰고, 다른 권한은 주지 마세요.
· 토큰과 비밀번호는 이 브라우저(localStorage)에만 저장돼요. HTML·공개 저장소·Gist 본문 어디에도 들어가지 않아요.
· 암호화 비밀번호를 넣으면 Gist에는 {"e2ee":true,"salt":…,"iv":…,"ct":…} 암호문만 남아요 (PBKDF2-SHA256 15만 회 + AES-256-GCM).
· 토큰·비밀번호는 아무에게도 공유하지 마세요. 기기를 잃어버렸다면 GitHub에서 토큰을 바로 폐기(revoke)하면 돼요.
아이폰에서 이어서 쓰기 — 같은 주소를 열고 여기에 같은 토큰 + 같은 비밀번호를 넣으면 내 비공개 Gist를 자동으로 찾아 기록을 그대로 불러와요. (Gist ID를 몰라도 됩니다)
🚀 GitHub Pages에 올리는 방법 (코드는 공개 · 기록은 비공개)
  1. 저장소에 index.html(이 파일), manifest.json, icon-180.png, icon-512.png를 올려요.
  2. Settings → Pages → Branch main / /root → Save.
  3. https://oof6uoh-coder.github.io/ 접속 → 위 칸에 토큰을 넣고 연결하고 동기화.
  4. 아이폰 Safari에서 열고 공유 → 홈 화면에 추가 → 앱처럼 실행돼요.

레벨·퀘스트·투두·오답노트는 내 브라우저 + 비공개 Gist에만 있고, 저장소에는 아무 기록도 들어가지 않아요.
